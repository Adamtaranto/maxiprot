# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

`maxiprot` is a Python bioinformatics CLI that selects the best miniprot alignment per locus. It reads miniprot GFF3 output (which must include `##PAF` header lines carrying `AS:i`, `ms:i`, `np:i`, `fs:i`, `st:i`, `cs:Z` tags), scores candidates, and emits spec-compliant, coordinate-sorted GFF3 (gene → mRNA → multi-line CDS sharing one `ID`) plus an optional TSV summary. Typical pipeline:

```
miniprot --gff genome.fa refs.faa | maxiprot filter - | maxiprot extract - -g genome.fa > best.faa
```

The session runs in the conda env `maxiprot` (configured in `.claude/settings.json`), which provides `miniprot` and `samtools`. Note: that settings file prepends the env's bin dir to PATH with a literal unexpanded `$PATH`, so core utilities may be missing in sandboxed shells — prefix commands with `export PATH="$PATH:/usr/bin:/bin"` if `mkdir`/`head` are "not found".

```bash
pip install -e '.[dev,test]'     # dev install

pytest tests/test_filter.py::test_prefer_intact_over_best    # one test

ruff check ./src/maxiprot ./tests
ruff format ./src/maxiprot ./tests
mypy src/maxiprot
pre-commit run --all-files
```

CI: pytest matrix 3.10–3.13 + mypy job (`pytest.yml`), check-only ruff on PRs (`ruff.yml`, version pinned to the pre-commit rev), PyPI trusted publishing on `v*` tags (`release.yml` — requires the PyPI trusted publisher to be configured).

## Architecture

Src layout: `src/maxiprot/`. Both subcommands expose `add_arguments(parser)`, `run(args) -> int`, and `main(argv) -> int` (tests call `main(argv)` directly).

- `cli.py` — real argparse subparsers (`filter`, `extract`) dispatching via `set_defaults(func=...)`; `--version` at top level and per subcommand; BrokenPipeError guarded via `ioutils.guard_broken_pipe`.
- `gffio.py` — single source of truth for GFF3/PAF parsing and formatting: `GffFeature`/`PafRecord` dataclasses, `iter_gff3()` streaming parser (yields both kinds), `parse_attributes` (URL-decodes), `gff3_escape`/`gff3_unescape`, `format_gff_line`.
- `ioutils.py` — `open_output`, `read_lines` (streaming; `-` = stdio), `guard_broken_pipe`.
- `scoring.py` — `parse_cs()` (miniprot cs:Z → identity/substitution counts), `compute_alignment_metrics()` (pid_aa from cs:Z with `nmatch/alen` fallback; `cov_aa = (qe-qs)/qlen`; positives from `np:i`; all clipped to [0,1]; missing tags fall back with warnings, never KeyError), `Weights` dataclass and the `SCORE_MODES` registry (`ms_cov_pos` default, `AS`, `ms`, `pid_cov`, `pid_cov_len`, `length`, `linear`, `geom`).
- `filter.py` — pipeline stages, each unit-testable: `load_input` → metrics/scores → `apply_gates` (gates always exclude; non-strict fallback emits best flagged `passes=False`) → `cluster_into_loci` (vectorized single-linkage; locus label `tname:strand:index`) → `select_per_locus` → `attach_mrna_ids_to_winners` (Target-name match requiring overlap, then CDS-union overlap ≥0.5) → emission + `build_tsv` (TSV only with `--out-tsv`; never stderr).
- `emit.py` — GFF3 writer: synthesizes one shared CDS ID per transcript (`{mrna_id}.cds` — real miniprot CDS lines carry no ID), dedups gene/mRNA IDs under `all_passing`, converts PAF 0-based → GFF3 1-based on the synthesized path, coordinate-sorts blocks, writes `##sequence-region` lines.
- `extract.py` — GFF3 → FASTA using Biopython (`Seq.translate` all NCBI tables, IUPAC-preserving revcomp) and pyfaidx; order-independent `parse_gff` (CDS-before-mRNA merges into shell records); downstream CDS phases verified against cumulative length (WARN on frameshift mismatch); missing contig → skip + exit 1.
- `logs.py` — rich-based `init_logging` used by both subcommands; removes only its own tagged handlers (so pytest caplog survives); logs to stderr only.
- `_version.py` — generated by hatch-vcs; never edit. `__init__.py` exports `__version__` with an importlib.metadata fallback.

## Conventions and gotchas

- Docstrings are numpydoc style; ruff format uses single quotes, line-length 88; mypy `disallow_untyped_defs` (pandas-heavy modules have `warn_return_any` off via overrides).
- Tests call module `main(argv)` directly (no subprocess), capture with `capsys`, use `tmp_path` for all I/O, `caplog` for warnings, `monkeypatch` for stdin. Shared fixture builders (`paf_line`, `gff_feat`, `wrap_gff`, `make_cs`) and the `assert_valid_gff3` checker live in `tests/conftest.py`. Fixture CDS lines must NOT carry `ID=` (matching real miniprot output).
- `tests/data/` holds a genuine miniprot fixture (mini genome + refs + raw miniprot GFF3) with golden filter outputs; regenerate goldens only deliberately (they are exact-text compared). Test files must be named `test_*.py` (pre-commit hook).
- Exit codes: 0 success, 1 partial data errors (extract), 2 usage/input errors.
- `.dev/` holds untracked scratch genomes used to regenerate `tests/data/` fixtures.
